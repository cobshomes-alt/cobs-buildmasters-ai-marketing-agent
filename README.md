# COBS Buildmasters AI Marketing Agent

Private, approval-first marketing operations foundation for **COBS Buildmasters Ltd** in Adenta New Legon, Ghana.

## Included

- Responsive Next.js / TypeScript marketing dashboard
- Navy, grey and gold COBS brand system
- Supabase schema with row-level security
- Content approval version safeguards
- Server-only Meta publishing gate

## Run locally

1. Copy `.env.example` to `.env.local`.
2. Configure Supabase and server-only credentials.
3. Apply the SQL migration in `supabase/migrations`.
4. Run `pnpm install` and `pnpm dev`.

> Meta publishing, OpenAI generation, Supabase authentication and analytics require production credentials and platform approvals before use.
